## English

### 📝 Project Overview

This is a high-quality, professional-looking "Cookies & Privacy" portal designed for **April Fool's Day**. It tricks users into interacting with a formal-looking interface to bypass browser auto-play restrictions, eventually leading to a full-screen video with audio.

### ✨ Features

  * **Modern UI**: Sleek card design with glassmorphism (blur) effects.
  * **Bilingual Support**: Automatically detects browser language (Chinese/English) and provides a manual toggle.
  * **Seamless Interaction**: Captures user click events to allow video playback with audio.
  * **Slide-in Privacy Panel**: A professional, animated privacy policy layer.

## 简体中文

### 📝 项目简介

这是一个专为**愚人节**设计的、具有高度专业感的“Cookie 与隐私确认”门户页面。它通过一个极其正式的交互界面诱导用户点击，从而绕过浏览器对视频自动播放（带声音）的限制，最终呈现全屏视频效果。

### ✨ 功能特性

  * **现代 UI 设计**：采用毛玻璃效果和精致的卡片式布局。
  * **双语支持**：自动检测浏览器语言（中/英），并提供手动切换按钮。
  * **无缝交互逻辑**：通过捕获用户点击，完美解决现代浏览器带声音视频自动播放的问题。
  * **滑入式隐私面板**：包含一个带动画效果的专业隐私政策页面。
